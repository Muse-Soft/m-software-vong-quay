# Vòng Quay — Xe đạp thủ công khung thép

Vòng Quay là hãng xe đạp thủ công nhỏ, chuyên làm xe đạp khung thép đo theo người đạp: từng chiếc được hàn, sơn và lắp ráp thủ công trong xưởng.

> Lưu ý: đây là bản demo. Giá trên trang là giá mẫu; địa chỉ, điện thoại và thông tin thật đang để placeholder [CẦN BỔ SUNG].

## Demo trực tuyến

- https://m-software-vong-quay.genalpha.dev

## Cách xem / chạy

Mở file `index.html` bằng trình duyệt, hoặc chạy máy chủ tĩnh tại thư mục gốc:

```sh
python3 -m http.server 8000
```

rồi mở http://localhost:8000

## Các tệp chính

| Tệp | Nội dung |
| --- | --- |
| `index.html` | Trang landing duy nhất: hero, triết lý, bộ sưu tập, quy trình, câu chuyện xưởng, bảng giá mẫu, form đặt lịch (chỉ giao diện) |

## English summary

Vòng Quay is a small handmade steel-frame bicycle workshop. This is a single landing page demo showcasing its philosophy, collections, build process, and sample pricing.
